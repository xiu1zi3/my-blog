### AI Agent 发展历程

大语言模型诞生以后，人们期待凭借大语言模型的能力，也许能打造自主运行的 AI Agent。
- Auto GPT（2023.04）：AI Agent 框架，受限于模型能力，并不好用
2025年，AI Agent 初具雏形，一定程度自主运行。它们能力的边界和 Openclaw 差不多，相比 OpenClaw 少一个即时通讯，不像个人助理而更像工具。
- Claude Code（2025.02）
- Gemini CLI（2025.06）

*注意区分模型和框架。Claude Code 并不是只能用 Claude，Genmini CLI 并不是只能用 Gemini，它们本质是 AI Agent 框架，可以对接不同的模型。*

### OpenClaw 与 AI Agent 应用的关系

![](/assets/article-images/article-15-1.png)

OpenClaw 仅仅是人与大语言模型的界面/接口，是 AI Agent 应用中不是AI的那部分。AI Agent框架本身没有智慧，龙虾助理的聪明程度取决于背后装的模型。


### 大语言模型的能力

> 外界call模型：大语言模型的唯一能力是“文字接龙”。外界输入prompt，模型给出回复。模型预测合适的文字接龙符号，加到未完成的句子的尾部，一并再次输入，若干次对输入的prompt多加1个token，直到接龙完整。

> 上下文长度：语言模型的输入不能太长。输出同样不会太长。否则某一刻的输入+输出就会超过输入上限。语言模型能处理的token序列数量上限叫 context window。


### 龙虾如何知道自己是谁
电脑本地有若干md文档描述了龙虾和主人的身份信息，每次对话，身份信息作为 system prompt 与用户消息一并传给模型。

电脑本地存有：
- 身份信息（SOUL.md, IDENTITY.md, USER.md, MEMORY.md）
- 可用工具，如何用工具
- 模型的行为（AGENTS.md）
- 可用SKILL
- 之前的记忆存在哪

### 多轮对话的运行
第一轮对话，给模型的是 system prompt + 用户消息
此后的每轮对话，给模型的是 system prompt + 用户消息 + 之前发生的所有事

这是因为大语言模型“每天醒来就失忆”，仅完成当前输入的文字接龙，要是不说明对话记录，语言模型就不知道过去发生了什么。
*由于每次都读之前的记录，看似很短的对话也可能消耗大量的token。*

### 龙虾如何使用电脑

#### 使用工具
Openclaw 可以使用电脑上的工具，包括可以执行**任何** shell command 的 exec工具。多数情况下，语言模型不是让龙虾盯画面鼠标点击，而是输出shell command让龙虾操作电脑。
除了电脑自带的工具，AI Agent 还能自主创作工具。例如语言模型输出脚本，龙虾把脚本写在电脑本地，这就诞生了一个新工具。

#### 特殊工具 Sub-agent
拆分任务，召唤更小的龙虾完成low-level的任务。
虽然亲子龙虾接的是同一个模型，Sub-agent 的意义在于，Sub-agent 繁琐的过程不出现在亲代龙虾与模型的对话，节省了 context 的使用。
*子代龙虾不允许繁殖。Openclaw 禁止 Sub-agent使用 Sub-agent工具，以防层层外包，光传话不做事的状况。*

#### SKILL 是工作的SOP
SKILL 是描述工作流程的文档，SKILL 里面可以使用工具。人类和语言模型都能自主创造 SKILL。
不同文件夹存储了若干SKILL.md 文档，SKILL全文的长度可能超过 context window。
System Prompt 包含了 SKILL 的主题、路径、说明信息，让模型选用SKILL，只有需要的SKILL的内容被加入对话。
*如此方式节省了 context 的使用，也体现了 Context Engineering。*

### 龙虾如何记忆
Openclaw的特色之一是长时间运行，上下文窗口总有不够用的一天。
有个粗糙的解决办法是，按下 New Session 按钮开始新对话。
好在 New Session 也不会让龙虾助理完全失忆，因为 Openclaw 默认配置下prompt包含了一个要求，将每天的记忆和重要事件记录到电脑本地：
1. 日记：memory/YYYY-MM-DD.md
2. 长期记忆：MEMORY.md
memory recall：取得跨 session 的记忆，本质是对md文档做RAG。
默认记忆系统的搜寻记忆比较弱，建议安装插件来增强能力。


### 龙虾如何定时工作

#### 龙虾的心跳机制
*在龙虾以前，AI Agent 未引入心跳机制。*
定时戳一下语言模型，从而让龙虾执行 HEARTBEAT.md描述的任务。
任务可以是具体的，比如规定每半小时检查一遍邮件；也可以是你与龙虾助理已经具有的共识，比如其他文件描述过的“你的人生目标”。

#### 重要工具 Cron job 系统

Cron Job 排程系统是重要工具之一，龙虾为周期任务设置排程。
排程也会戳龙虾，也就是增加心跳，心跳的结果不是执行 HEARTBEAT.md，而是执行之前约定的任务。

*排程系统让大语言模型“学会等待”，以完成更复杂的操作，比如使用其他 AI*



### 龙虾如何长时间自主运作

#### Context Compression 机制
随着对话记录越来越长，上下文窗口终究有不够用的一天。
当给出的文字可能超过 context window，让大语言模型为比较旧的对话记录生成摘要。
压缩可以递归发生，可能损失重要信息，建议安全规则放在 MEMORY.md 才靠谱。

> 使用cron进程和crontab命令实现定时任务的方法和语法，以及一些常见的实例。cron可以配合shell脚本，实现各种复杂的定时需求。




### 要点总结

> AI Agent 框架仅仅是人与大语言模型的界面/接口，龙虾助理聪明程度取决于背后装的模型。
> 大语言模型没有记忆，它唯一的能力是接龙当前文字，每一次对话都是“重启”。

龙虾的核心技术在于 Context Engineering，用少量的 token 完成任务。
