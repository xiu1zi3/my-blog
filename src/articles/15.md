## 类与对象

### 回顾

- **1 对多**：一个 Java 源文件中可以有多个 class
- public class 并不是必须要有的
- 一个 class 文件对应生成一个.class 字节码文件
- **至多 1**：如果源文件中要定义公共的类(public class),有且只能有一个,并且该源文件的名称一定要与类名一致
- **1 对 1**：每一个 class 中都可以编写 main 方法,都可设定程序的入口

### 类、对象

类是构造对象的模板或蓝图 什么是对象？ 把类想象成月饼模具，对象就是模具压出来的月饼 由类(Class)构造对象(Object)的过程，就叫做创建类的实例(Instance)

#### 面向对象和面向过程的区别

**面向过程**：是分析解决问题的步骤，然后用函数把这些步骤一步一步地实现，然后在使用的时候一一调用则可。性能较高，所以单片机、嵌入式开发等一般采用面向过程开发

**面向对象**：是把构成问题的事务分解成各个对象，而建立对象的目的也不是为了完成一个个步骤，而是为了**描述某个事物在解决整个问题的过程中所发生的行为**。面向对象有封装、继承、多态的特性，所以**易维护、易复用、易扩展**。可以设计出低耦合的系统。 但是性能上来说，比面向过程要低

> 和 Java 一样，C#也是面向对象。而 JS 是基于对象

### OOP 三大特征

面向对象三大特征：封装 继承 多态

## 构造方法

构造方法，也叫构造函数/构造器

一句话，指定好创建对象的内容。调用构造方法---> 创建对象

```java
User n = new User();
```

> 如果没有定义构造方法，系统默认给该类提供一个无参数的构造方法

### 语法格式

一般方法：

```java
[修饰符列表] 返回值类型 方法名(形式参数列表){
    方法体
}
```

构造方法：

```java
[修饰符列表] 方法名(形式参数列表) {
    方法体
}
```

### 构造方法的参数

- 无参数的构造方法

```java
public User(){
    ...
}
```

- 含参数的构造方法

```java
public User(int id, String name){
    ...
}
```

无惨构造方法和有参构造方法的区别:

- 无参构造方法会赋默认值
- 有参构造方法将变量初始化赋值!(多个有参构造方法联系到方法重载!)
