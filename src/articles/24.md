### 方法重载

> 重载与重写，自己的话粗浅解释： 方法重载是**横向的多态** 方法重写是**纵向的覆盖**

方法名相同，参数列表必须不同（也就是，参数类型、参数个数或者参数排列顺序不相同）

而方法返回的类型，可以相同，也可以不同

### 可变参数

jdk1.5 开始，Java 支持传递同类型的可变参数给一个方法

在方法声明中，在指定参数类型后加一个省略号(...)

**可变参数在一个方法中只能存在一个，它必须是方法的最后一个参数**

这样，传进来的参数是元素类型是省略号前的数据类型的数组

#### 语法：用户交互Scanner

```text
Scanner s = new Scanner(System.in);
```

`Scanner`类读入字符串：`next()`和`nextLine()`； 读入前判断是否还有输入的数据`hasNext()`、`hasNextLine()`。

### 语法：label流程控制

java 没有`goto`关键字，java 使用的是标签(label)：

```java
outer:for(xxx){
    for(xxx){
        if(xxx){
            continue outer;
        }
    }
    xxx
}
```
